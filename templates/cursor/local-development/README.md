# Cursor · Local development

1. Open Settings > Agents > Approvals & Execution, choose the «Allowlist» run mode and add four commands: npm run lint, npm test, git status and git diff.
2. On the same screen, under «Read Access», choose «Workspace».
3. Turn on «File-Deletion Protection» and check that «External-File Protection» is on.
4. Copy the text and paste it into Cursor, which will show you the change before saving it.
