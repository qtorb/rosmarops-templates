# Cursor · Read only

1. Open Settings > Agents > Approvals & Execution and choose the «Allowlist» run mode, with no commands on the list.
2. On the same screen, under «Read Access», choose «Workspace».
3. When you start each conversation, choose «Ask» mode in the agent panel (Ctrl+I).
4. Copy the text and paste it into Cursor, which will show you the change before saving it.
